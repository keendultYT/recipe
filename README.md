푸어 레시피와 간단한 유량 게임이 있습니다.
레시피는 임의로 넣어둔 것이고 각자 레시피 추가해서 사용 가능합니다.
기록의 경우 각자 폰의 브라우저에 저장되기 때문에 사용자 이외에는 아무도 기록을 볼 수 없습니다.
브라우저 변경 되면(예 : 삼성인터넷 -> 크롬) 역시 기록은 옮겨지지 않습니다. 
직접 백업 후 백업 불러오기를 진행시 다른 브라우져나 폰으로 옮길 수 있습니다.
해당 브라우저에서 '앱스 화면에 이 웹페이지를 추가할까요?'를 진행하면 앱 처럼 사용 가능합니다.
만든 레시피는 공유하기 버튼을 통해 다른 사람에게 공유해줄 수 있습니다.
기록은 이미지로 저장하기를 눌러 따로 저장 및 공유도 가능합니다.
